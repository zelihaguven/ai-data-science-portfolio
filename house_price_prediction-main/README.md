# House Price Prediction

## Project Overview

This project aims to develop a machine learning model that predicts house prices with minimal error based on a given dataset. The model will be evaluated and submitted to a Kaggle competition.

## Dataset

The dataset used in this project includes various features related to house sales, such as:

- **LotArea**: Lot size in square feet
- **OverallQual**: Overall material and finish quality
- **OverallCond**: Overall condition rating
- **YearBuilt**: Original construction date
- **GrLivArea**: Above grade (ground) living area square feet
- **SalePrice**: Sale price of the house
